# Offline Budget Tracker (Interactive Demo)

A zero-dependency, local-first personal finance dashboard running entirely client-side in browser memory.

---

## Architectural Mechanics
* **Zero External Dependencies:** Built purely with standard vanilla HTML, CSS, and modern JavaScript. No frameworks, CDNs, or external bundles.
* **Complete Data Privacy:** Runs locally in your browser. Zero telemetry, zero analytics tracking, and zero cloud API connections.
* **Anti-SaaS Model:** Standalone, single-file distribution eliminating recurring subscription fees and third-party account requirements.
